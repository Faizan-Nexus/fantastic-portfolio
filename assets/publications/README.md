# Publication Assets

Place your publication certificate images and conference logos in this folder.

## Naming Convention
Use descriptive names so the HTML can reference them easily:

| File | Purpose |
|------|---------|
| `icomet_certificate.png` | ICoMET 2026 acceptance / presentation certificate |
| `icomet_logo.png` | ICoMET conference logo |
| `icbeem_certificate.png` | iCBEEM 2026 presentation certificate |
| `icbeem_logo.png` | iCBEEM conference logo |

Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp`
